# Подкрепления атакующего у ресурсного объекта — 5В.4а

27.10.2026. Это часть общего боя5В, не подключение всех боевых фаз и охраны.

## Контракт

- Второй заранее отправленный CAPTURE того же владельца и того же канонического
  OBJECT/siteId входит в существующий ресурсный бой, не создаёт отдельный.
  Сторонний игрок и защитник не становятся атакующей стороной по дружбе.
- Допуск — только running с ещё не рассчитанным раундом. Выбор номера раунда,
  idempotent admissions и worker остаются в `FleetBattleService::reinforceSpace`.
  Уже переданный в процесс раунд не дополняется.
- Прибытие всё ещё проверяет реальное достижение OBJECT. За время боя объект
  вращается: сравнивать прибывшего со старой POINT первого freeze нельзя.
- Повторная обработка ATTACK с battleWait не добавляет группы второй раз.
  Состав/XP/груз/топливо остаются раздельными. Доклад и результат — общие.
- Если pending-подкрепление принято, но бой завершился раньше его раунда,
  ему не начисляются потери/XP/трофеи. Оно получает итог объекта и продолжает
  CAPTURE либо обычный возврат, не остаётся бесконечно в pause=battle.
- Чужая сторона/завершённый бой при прибытии дают обычный resourceFailure
  и возврат через CAPTURE; не вечный due retry. Условия владения/лимитов при
  самом занятии объекта по-прежнему проверяет ResourceBaseService.
- Новые отправки к уже воюющему объекту пока закрыты прежним preview/validator.
  Индивидуальный FLEET-перехват ресурсной базы не открывается. Дружественная
  DEFEND и подкрепления защиты — последующие подэтапы, не реализованы здесь.
