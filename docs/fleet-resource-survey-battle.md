# Активное обследование в общем бою — 5В.3

26.10.2026. Продолжение5В.2, только текущий backend. SPA не изменялся.

## Контракт

- Работающий геологоразведочный флот владельца защищённого гиганта/сектора
  участвует в общем бою вместе с фактически присутствующей охраной/добытчиками.
  Он не блокирует весь захват только из-за активной фазы RESEARCH.
- Допуск проверяет точный канонический адрес/siteId, активную команду,
  server survey/hold, UUID прохода и согласованность часов/ставки. Это не допуск
  любой команды с произвольным hold. Отдельный assertAvailable по-прежнему
  запрещает прерывать проход с уже подготовленным результатом SurveyResults.
- Существующий freeze учитывает бортовое топливо до момента встречи и
  превращает RESEARCH в OBSERVE/pause=battle: удаляет survey/hold/planStep.
  Результат прерванного прохода не выдаётся, знание/старые доклады не стираются.
- Result-plan назначает выжившему ту же каноническую позицию. После применения
  результата адаптер автоматически строит обычный возврат домой вместо остатка
  прежнего плана. Ручной Resume не нужен; прерванный проход не повторяется.
  Обследователю не назначается платная послебоевая стоянка. При нехватке топлива
  действует обычная остановка возврата с уведомлением, без выдачи топлива.
- Атака относится ко всему siteId, не к одному геологоразведчику. Другие
  сектора той же орбиты не включаются. Скрытие ресурсного базирования от
  индивидуального перехвата/сенсоров не ослаблено.

## Оставшиеся границы

Это только активное обследование своего защищаемого объекта. Другие активные
hold, дружественная ресурсная DEFEND и подкрепления общего боя остаются отдельными
подэтапами. Работающий добытчик, приписанный к атакуемой базе, но находящийся
у другого объекта, по-прежнему закрывает захват до согласования его checkpoint.
Произвольные падения на промежуточной строке application plan не моделируются.
B026/B029 и прочие отложенные находки не исправляются этим подэтапом.

PHP lint изменённых PHP, CoreContracts140/0 на host и в основном контейнере,
`git diff --check` пройдены. После проверок основной сервер работает.

## Автоматический возврат 27.10

По уточнению пользователя выбрана автоматическая отправка домой, а не ручная
послебоевая пауза. Предыдущий раздел проверок описывает старое поведение.

- До freeze в durable participant записывается ID рабочего RESEARCH.
  Frozen OBSERVE получает server-only `surveyBattleReturn=true` без survey/hold.
- Result-plan не назначает обследователю платную стоянку. После commit,
  пока защита боя ещё действует, адаптер вызывает узкий внутренний путь
  существующего отзыва: отменяет остаток плана и строит возврат к своей базе.
- Уничтоженный флот не возрождается. Исполненный frozen ID при повторе
  settlement не запускает второй возврат, включая уже созданный pause=fuel.
  При нехватке топлива флот останавливается штатно с сообщением.
- Knowledge/SurveyResults за прерванный проход не начисляются; прежнее знание
  сохраняется. Боевая формула, XP, доля потерь топлива и frontend не менялись.
- CoreContracts143/0: пять прежних проверок допуска и три новые проверки
  server-only признака возврата. PHP lint и143/0 пройдены на host и в основном
  контейнере; `git diff --check` без замечаний. Второй сервер не запускался.
