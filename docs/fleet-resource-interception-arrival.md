## Контракт по актуальному коду

`FleetInterceptionService::observation/matchesCurrent` проверяет доступность,
фазу и сигнатуру. В resource OBJECT `sheltered` закрывает стоянку/добычу;
знание ID и прежний свежий снимок не открывают скрытую цель.

Если цель во время перехвата прибывает к защищённому объекту и скрывается:

- `last_position` продолжает сохранённый участок без скрытого сопровождения;
  на прибытии повторяется проверка контакта, затем pause=target и сообщение;
- `stop` останавливается в фактической точке при потере контакта;
- скрытый FLEET не становится индивидуальным боем или неявной CAPTURE;
- если цель остаётся допустимой и встреча действительно состоялась у объекта,
  существующий FleetSpaceBattleService повторно собирает общий `battleContext`
  и проверяет весь состав. Этот запасной боевой путь не обходит observation.

Проход process получает новые сведения только через реальные сканы. Новый
снимок после смены сигнатуры может пересчитать участок; старый снимок не
дополняется живой траекторией. Обычный active MOVE не меняет сигнатуру
каждую секунду, при скрытии новая корректировка не появляется.
