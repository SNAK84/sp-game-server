## Реализация

- Только свежий скан текущего активного MOVE_IN_SYSTEM на tier3 добавляет route:
  start/end, motionStart/motionEnd, startsAt/endsAt. Остальные поля команды,
  будущие цели, cargo/fuel/XP не копируются в DTO. У tier1/2 поля route нет.
- Выход из системы показывает служебную орбиту текущей системы, fuelStop —
  реальную точку остановки; не раскрывается дальний OBJECT всей миссии.
  FLEET-endpoint превращается в POINT без ID другого неизвестного флота.
- Копия участка строится раз на цель в скан, переиспользуется для сильных
  наблюдателей. Буфер/TTL/ActualData прежние, новый polling/канал не вводится.
- Карта рисует конечный участок существующим пунктиром. Маркер интерполируется
  между сохранёнными физическими опорами в XY, затем проецируется существующей
  нелинейной картой. Snapshot не мутируется; движение не выходит за конец MOVE.
- Потеря свежести замораживает последнюю показанную позицию без отката назад.
  Первый показ уже stale-контакта остаётся в наблюдённой точке. При снижении tier
  маршрут больше не используется; cache очищается при исчезновении контакта,
  уходе со страницы/смене системы. Старый полный маршрут остаётся только
  исторически известным снимком, не источником нового сопровождения.
- Карточка контакта выводит «Откуда/Куда» только на разрешённом уровне;
  в остальных случаях поясняет прежнюю линию курса. Серверные полные описания
  исследования135/корабля221 обновлены, клиент не дублирует их текст.
- Скрытие самой EXPEDITION, переходов и неподвижных ресурсных флотов сохранено.
  Разрешение/прогноз боевого перехвата и ручная фаланга не менялись.
