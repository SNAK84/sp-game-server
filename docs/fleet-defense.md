# Оборона дружественного объекта

Миссия `DEFEND` использует существующий путь `SendMission → PlayerQueue → EventLoop`
и цепочку `LOAD → MOVE… → DEFEND → MOVE… → UNLOAD → STAY`. ACK подтверждает принятие,
а актуальное состояние доставляет обычный `ActualData`.

## Доступность

- Чужая принадлежащая подтверждённому другу планета или луна. Заявка сама по себе
  дружбой не считается. Минимальная система друзей: `mode=friends`, действия
  `request`, `accept`, `remove`, поле `data.id` — числовой ID игрока/связи.
- Собственные объекты, обломки и свободные координаты не являются целью обороны.
- Один уровень Склада альянса (постройка 34) предоставляет одно место для флота,
  независимо от его владельца. В пути места не резервируются; при прибытии
  выполняется повторная проверка. Планета и луна имеют независимые склады.
- Длительность `data.duration` — целое число секунд: 3600, 7200, 14400, 28800,
  43200, 57600, 115200; по умолчанию 3600. Это время удержания ПОСЛЕ прибытия.
- Общий лимит миссий по компьютерной технологии сохраняется.
- Полноценные альянсы, noob/vacation-защита не добавляются искусственно.

## Снабжение

Отправитель загружает бортовое топливо для полного маршрута туда и обратно.
Расход удержания не входит в эту загрузку и не списывается с борта.

Принимающий объект платит своим дейтерием:

`дейтерий/час = Σ(число кораблей × базовый расход) × FleetDefendFuelPerHourFactor`.

Коэффициент по умолчанию `0.1`; расход всех удерживаемых флотов суммируется.
Он включён в общий серверный расчёт ресурсов и его `perhour`. Реальное списание
интегрируется только по интервалу удержания; чтение snapshot не списывает повторно.
Поступление/убытие флота актуализирует ресурсы до изменения состава удержания.
После боя будущая ставка пересчитывается по выжившим кораблям.

Исчерпание дейтерия завершает удержание досрочно. Прогноз учитывает производство,
все флоты и изменение суммарной ставки после ухода очередного флота. Пополнение
до исчерпания может продлить удержание до исходного срока. Дейтерий планеты
никогда не используется для удержания на её луне.

Владелец может отозвать уже удерживаемый флот вне боя (`RecallDefend`, числовой
`fleetId`). Отзыв обрабатывается штатным PlayerQueue/due pipeline. Общий отзыв
любых ещё летящих миссий этим действием не реализуется.

## Бой и сообщения

Удерживаемые флоты входят в сторону защиты со своими технологиями и опытом.
Прибытие во время боя использует существующий admission следующего незафиксированного
раунда. Во время боя нельзя отозвать флот; истёкшее удержание завершается после боя.
Выжившие продолжают удержание до срока либо возвращаются при отсутствии снабжения.
Владелец поддерживающего флота получает боевой доклад и обновление состояния.
Начало/окончание удержания сообщается обоим игрокам существующими Messages/ActualData.

## Установка и проверки

До перезапуска применить `migrations/20261018_defend_moon_depot.sql`.
Таблицу `friends` создаёт штатный `Friends::init($saver)`; сохранение — RepositorySaver.

Изолированная проверка без MySQL и живых данных:

```sh
docker exec -w /var/www/html swoole_app php tests/FleetDefendSwooleTest.php
```

Она использует настоящие Swoole Tables и запрещающий SQL guard. Проверяются
права друзей, request/queue duration, лимиты, прибытие, оплата, общий срок исчерпания,
луна, возврат, отзыв, бой и продолжение удержания. Имеющиеся ограничения runtime
commit/flush и общий протокол результатов команд этой миссией не перепроектируются.

## Проверки при реализации

- 17 сценариев на реальных изолированных Swoole Tables, без SQL.
- 27 регрессионных проверок исследований/ресурсов, без SQL.
- Регрессии: FleetTransportTest, FleetAttackTest, FleetSpyTest, FleetPushTest,
  FleetLimitsTest, FleetBattleTest, InformationPageTest, FleetRecycleTest,
  FleetColonizationTest, BattleReportPipelineTest, MoonFormationTest, MessagesTest.
- Настоящий SPA: заявка snak1 → snak_test, принятие, push отправителю без reload,
  сохранение дружбы при рестарте, успешный reconnect со свежим Friends snapshot,
  preview DEFEND, duration 3600/7200 и ширина 390 px.
  На собственной планете DEFEND отсутствует. Проверка не отправляла живую миссию:
  только путь до целевой тестовой планеты занимал бы около 29 минут.
- По разрешению пользователя на snak_test [1:3:2] установлен только ally_deposit=1.
  Остальные поля построек и ресурсы при подготовке проверены на неизменность.

Ограничения: система пока использует друзей, не альянсы. Места в пути не
резервируются (как в старом SP-Game). Полный живой цикл обороны в браузере не
ожидался; полный цикл, досрочный уход и бой проверены изолированно. Существующие
общие ограничения конкурентного runtime commit, сохранения до flush и нехватки
бортового топлива после боевых потерь не перепроектировались.
