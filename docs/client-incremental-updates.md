# Обновление существующего UI — B026

## Контракт

Серверный Page/ActualData — authoritative snapshot, его нельзя пропускать ради
стабильного интерфейса. При этом snapshot не является командой пересоздать DOM.

- У существующей сущности обновляются значения, классы, атрибуты, доступность
  действий и содержимое подсказки. Её DOM-узлы сохраняются.
- Создаётся только новая сущность, удаляется только исчезнувшая. При сортировке
  перемещаются существующие строки с сохранением focus.
- Не теряются раскрытые списки/команды/сообщения, выбор, прокрутка и ввод.
- Новый объект/другая страница могут создать своё содержимое. Общие селектор
  планет и TopNav переживают переходы между игровыми страницами.
- Локальные таймеры, интерполяция движения и намеренная simulation ангара
  сохранены. Новый server snapshot по-прежнему корректирует их baseline.

## Доказанная причина

27.10.2026 на основном dev через настоящий SPA прослежены штатные сенсорные
ActualData примерно раз в10 секунд. Ping не является причиной. Маршрутизация
ShowPage сохраняла экземпляр страницы, но её render заменял дочерние элементы:

1. RenderPlanetsList очищал select и создавал новый planetselectmenu.
2. Обзор явно скрывал tooltip, очищал список флотов и создавал новые строки.
3. Галактика останавливала animation, заново назначала даже неизменившиеся
   canvas.width/height, пересоздавала случайные частицы пояса, скрывала/показывала
   все подписи и заменяла содержимое открытых панелей.
4. Аналогичная пересборка обнаружена у летящих флотов, сообщений и друзей.

До исправления при открытом селекторе браузер подтвердил замену select на
ActualData. Для обзора зафиксирован вызов ToolTip.hide из
renderFlyingFleetsOverview; для галактики — повторные stopAnimation, canvas
1251→1251/764→764 и generateAsteroidBelt при неизменной системе.

## Изменённые файлы текущего клиента

Все пути ниже относительно `/var/www/spa.snak84.ru`:

- `js/BasePageClass.js`: сохранение общего select/widget/option/li/подписи,
  инкрементальное обновление TopNav и общих карточек состава/контакта;
  безопасное перемещение строк и обновление native select.
- `js/pages/OverViewPageClass.js`: строки флотов/контактов по ID, без очистки
  списка и скрытия подсказки оставшейся строки.
- `js/pages/GalaxyPageClass.js`: непрерывная animation в той же системе,
  сохранение частиц пояса, canvas без сброса размеров, обновление подписей,
  свободных орбит, сведений/легенды и открытой карточки объекта на месте;
  фоновый snapshot не стирает ещё не отправленный ввод навигации.
- `js/pages/FleetsPageClass.js`: карточки полёта, команды, кнопки, границы шкалы
  и варианты выбора целей обновляются на месте. DTO полёта заменяется свежим.
- `js/pages/MessagesPageClass.js`: строки по ID, обновление read/заголовка,
  сохранение раскрытия, checkbox/focus; постоянные кнопки пагинации.
- `js/pages/FriendsPageClass.js`: постоянные секции и строки по ID; при принятии
  заявки её строка переносится, а не пересоздаётся.
- `js/tooltip.js`: HTML-данные открытой подсказки обновляют существующие узлы;
  учитываются также изменения атрибутов/классов, а не только plain text.
  Переданные живые jQuery/HTMLElement сохраняют собственные обработчики.
- `js/GameBuildElement.js`: требования обновляются по ID; simulation/count/
  baseline/timers ангара не менялись в этом этапе.
- `js/pages/HangarPageClass.js`: состав заказа обновляет существующие строки.
- `tools/check_incremental_ui.py`: read-only browser-регрессия через явно
  указанную собственную Selenium-сессию. Не создаёт игровой сервер/аккаунт,
  не отправляет игровые команды и не содержит credentials.

Backend production-код, transport ActualData, частота сенсоров, механика
производства и сохранённые игровые данные не изменялись. Перезапуск не нужен.

## Проверки

Живые проверки выполняются на основном dev в браузере QA-аккаунта, а не на
изолированном игровом сервере. Отдельный долгий прогон галактики:123 секунды,
12 ActualData; select/widget/option/li/подпись/карточка/кнопка остались прежними,
focus и раскрытие сохранились, stopAnimation=0, canvas resets=0,
частицы/zoom/offset сохранены, JS errors=0.

Повторяемая проверка основных страниц:

```sh
python3 /var/www/spa.snak84.ru/tools/check_incremental_ui.py \
  --session <своя-selenium-session> --seconds 23
```

Проверяет galaxy, overview, fleets, messages, friends, buildings, researchs,
shipyard, defense. Для каждой страницы ждёт готовности и окончания начальной
анимации, затем отслеживает настоящие входящие обновления и идентичность всех
первоначальных DOM-элементов содержимого/селектора. Также проверяет сохранение
общих элементов между страницами, открытый список и focus; для галактики —
непрерывность animation/частиц/масштаба. Тест завершается ошибкой при провале.

Синтаксис JS проверяется компиляцией реального загружаемого кода в Chrome;
ESLint/Prettier конфигурации и Node в данном клиенте нет. Проверяются diff
от копий файлов до этого этапа и сохранение исходных CRLF в tooltip.js.

Финальный desktop-прогон:9/9 страниц,21 настоящий response,0 удалённых
первоначальных элементов и0 JS errors. Дополнительно viewport390×844:
2 ActualData с сохранёнными menu/focus/карточкой/zoom; горизонтального overflow
нет (scrollWidth=innerWidth=390), колесо над открытой карточкой работает.
Отдельный настоящий Page-response с action="" в той же системе тоже сохраняет
DOM, focus, zoom и ещё не отправленное значение ввода навигации.

Отдельно от живых ответов выполнены browser UI-fixtures без отправки игровых
команд: option rename/add/remove и fleet DTO add/update/reorder/remove.
Проверены свежие имя/цель/состав/бак/доступные действия, сохранённые команды,
focus после сортировки и узлы открытой подсказки. Настоящие строки флотов
сохранены, искусственные UI-строки удалены, исходные DTO восстановлены.

Настоящее наведение указателя на состав удерживаемого флота113: подсказка

## Границы

Обновление серверных данных не блокируется и не заменяется общим сравнением
snapshot. Ключ селектора охватывает только его отображаемые поля: ресурсы,
координаты движения и таймеры продолжают обновляться своим обычным путём.

При исчезновении источника подсказка закрывается штатно. Полная смена контекста
страницы/диалога может создать новое содержимое. Это не фоновая пересборка
прежней сущности. Старые проблемы навигации/ACK, зарегистрированные отдельно,
не объявляются исправленными этим этапом.

B001 повторно проявился при переходе «Флот»→«Галактика» на мобильном viewport:
модель новой страницы была готова, но общий Content пуст, карта отсоединена.
После reload мобильная проверка обновлений прошла. Это не доказательство
исправления навигации: наблюдение отдельно добавлено в существующую запись B001.
Позднее27.10.2026 B001 исправлен отдельным owner/generation guard, проверенным
на основном dev: [client-page-lifecycle.md](client-page-lifecycle.md).

Custom planetselectmenu использует закреплённый в клиенте jQuery UI1.14.1;
при обновлении этой библиотеки необходимо повторять browser-регрессию её
refresh/select, keyboard focus и раскрытого меню.
