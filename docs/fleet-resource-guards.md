# Платная послебоевая охрана ресурсного объекта — 5В.1

26.10.2026. Продолжение добычи, не прямая отправка кораблей из ангара.

## Изменения

- Рабочий MINING с ресурсной припиской и finish=stay теперь также допускает
  общий экономический settle/close перед боем. Приписка, груз и продолжение
  сохраняются. Повтор подготовки после durable close не возвращает старую добычу.
- Выживший собственный защитник получает оплачиваемую стоянку у того же siteId:
  OBSERVE/pause=battle/siteGuard и существующий base_fuel clock. Это не новая
  приписка и не возобновление добычи. Обычная произвольная pause охраной не стала.
- Расход пересчитывается по выжившему составу, резерв — по пути домой для
  посетителя или до резервной планеты/луны для ресурсной приписки. Бой не расходует
  стояночное топливо; новый clock входит в тот же application.changes результата.
- База учитывает платных посетителей, а при достижении резерва отменяет их
  прежнее продолжение и готовит эвакуацию. Топливо из груза автоматически не берёт.
- Resume/Recall согласуют время с уже сохранённым clock: Event.added_at может
  быть немного раньше последнего тика. Старый расход не возвращается и повторно
  не списывается. Редактирование сохраняет платную паузу, доставка согласует бак,
  слияние пересчитывает clock по новому составу. Последние три ветви в этом прогоне
  проверены статически, не новым живым рейсом.
- Личный FlyingFleets получает standing DTO. Tooltip использует существующую
  standingFuel, уменьшая бак только до резерва. Чужим этот DTO не передаётся.

объектная атака/захват занятой базы, активный hold и дружественная DEFEND с их

индивидуальный FLEET-перехват неподвижного ресурсного флота не открывается.
Вход подкрепления через FLEET в уже идущий ресурсный бой явно отклоняется
до мутаций: его послебоевое продолжение ещё не подключено. Обычный бой
перехвата в свободном пространстве и его подкрепления не меняются.
