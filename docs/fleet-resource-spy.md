# Ресурсное базирование: видимость и шпионаж

26.10.2026. Реализован отдельно согласованный слой после5В.0.
Не завершает захват занятого объекта/общий послебоевой контроль и не исправляет
B023; публичные отправка MINING и ресурсная DEFEND этим не открываются.

## Контракт

- Неподвижный флот у ресурсного OBJECT скрыт от мобильного обнаружения и
  индивидуального перехвата: IDLE, MINING, OBSERVE/охрана, пауза, DEFEND.
  Фильтр общий для сенсора и допуска перехвата; старый контакт теряет свежесть,
  но последняя историческая отметка живёт по прежнему сроку хранения.
- Реальный активный MOVE_IN_SYSTEM остаётся наблюдаемым, даже если в строке
  флота ещё сохранён OBJECT точки старта. Свободная POINT-стоянка не становится
  базированием только из-за совпадения радиуса/системы. Собственная видимость
  и состав собственного флота не скрываются.
- SPY20 с зондами направляется на занятый чужой ресурсный OBJECT с каноническим
  siteId. У пояса это один сектор, не вся орбита. Свой/свободный объект или
  объект в бою не является доступной целью SPY. Правила повторяются на прибытии.
- В докладе общий фактический состав защиты и, по прежнему порогу разведки,
  исследования владельца базы. Включаются свои присутствующие флоты и
  подтверждённая дружественная DEFEND; отсутствующие и другие сектора исключены.
  Боевой допуск отдельных фаз не ограничивает сбор шпионского снимка.
- Не раскрываются Fleet ID защитников, их планы/бак/груз, G/K, частное знание
  обследования и фиктивный планетарный склад. Доклад сохраняется как обычное
  сообщение с targetKind/snapshotAt, не является источником живого сопровождения.
- Используются прежние пороги, Factors, контршпионаж, возврат и уведомления SPY.
  Состояние реального владельца актуализируется обычным EventLoop к прибытию;
  фиктивные Account/Planet для объекта не создаются.
- При потере зондов формируются POINT-обломки в физической позиции объекта.
  Ключ fleetId/commandId предотвращает повторное добавление; запись/index/sync
  проверяются до удаления флота, отказ записи очищает незавершённую строку.

## Клиент

Собственные флоты базы уже используют компактные FleetOrbitCards. Новый дизайн
карточек не вводился. В карточке занятого чужого гиганта/сектора добавлена
«Шпионить»: передаётся OBJECT/siteId и SPY20 в штатное окно отправки.
В сообщении ресурсной базы только ships/research и время статического снимка;
планетарные отчёты сохраняют пять прежних разделов.

## Границы покрытия

- Полный живой SPY по сектору, дружественная ресурсная DEFEND, ветка уничтожения
  зондов/отказ хранилища обломков не воспроизводились; секторный отбор/маскировка
  проверены чистыми контрактами и статическим чтением общего collection path.

  отдельный слой. Шпионский снимок не разрешает прежний FLEET-обход охраны.
