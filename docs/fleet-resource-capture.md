## Контракт и реализация

Миссия CAPTURE45 использует цепочку LOAD (только планета/луна) → MOVE →
ATTACK проверки/общего боя → CAPTURE → STAY. С ресурсного источника LOAD нет.
Свободный объект пропускает бой; чужой собирает всю поддержанную фактическую
оборону одного siteId. Индивидуальный живой контакт/Fleet ID не требуется.
Добыча по-прежнему не атакует чужую базу автоматически.

ATTACK исполняется отдельным due-событием после MOVE commit. До snapshot боя
все участвующие MINING согласуются и закрываются одним экономическим моментом.
Используется существующий SpaceBattles: раунды в worker, состав/Factors/XP,
потери, груз/бак, доклады и POINT-обломки; не планетарный склад объекта.

После результата ATTACK хранит исход, возвращает выжившего атакующего в
канонический адрес объекта. Следующее CAPTURE выполняется после снятия боевой
блокировки. При ничьей/поражении или изменении условий — сообщение и штатный
возврат. При победе сначала штатная потеря прежней базы: отсутствующие
приписанные флоты получают резервную планету/луну; затем повторная проверка
лимитов и новое владение/приписка/платная стоянка. G/K объекта не трофей.

Входящие к своей ресурсной базе включены в существующую видимость обзора и
галактики с фильтром siteId; соседний сектор той же орбиты не смешивается.
Уведомления используют существующие PlayerQueue/ActualData, нового push-канала нет.
В карточке чужого объекта галактики — «Захватить» с предвыбранной CAPTURE.

## Границы текущего слоя

- Поддержаны своя IDLE-охрана, пассивные OBSERVE и платная послебоевая охрана,
  рабочие планетарные/ресурсные MINING. Неподдержанная фаза защитника отклоняет
  весь захват, а не исключает этот флот из общего боя.
- Активный hold, дружественная ресурсная DEFEND и подкрепления общего боя ещё
  не подключены. Полное требование этапа5 этим подэтапом не закрыто.
- Если у прежнего владельца есть приписанный к цели добытчик, работающий у
  другого объекта, захват явно закрыт до координации его loss-base/checkpoint.
- Произвольные падения между записью всех result rows не моделировались;
  штатный restart в полёте не доказывает полный crash-recovery любого момента.
- B026 (периодическое закрытие меню/перерисовка/tooltip) только зарегистрирован,
  не исправлялся. Прямые вылеты из ангара остаются отдельным этапом.
