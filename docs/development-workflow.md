## Публичный GitHub

Репозиторий публичный. Старую ветку backup/pre-cabinet-2026-11-03 сохранять
как исторический снимок. Текущие проверенные исходники сохранять отдельно
в backup/dev-stabilization-2026-11-13; не переписывать main или старый backup.

Первая новая точка — самостоятельный корневой commit без старой истории:
редакторские .vscode и *.code-workspace исключены из дерева, а вместе с ними
не должна наследоваться ранее раскрытая приватная конфигурация. Это **не**
удаляет утечки из уже опубликованной старой истории и не закрывает B053.
Перед push проверять именно публикуемое дерево на секреты с редактированным
выводом. Отсутствие срабатываний сканера не заменяет отзыва известных секретов.

Собирать дерево через отдельный временный Git index, используя текущие рабочие
файлы. Не переключать ветку, не очищать/переставлять основной index, не откатывать
незакоммиченные изменения пользователя. Следующие точки в backup-ветке должны
продолжать только её проверенную историю. Проверять совпадение локального и
удалённого SHA после push. Не создавать автоматических публикаций по таймеру.

Точка содержит код и примеры конфигурации, не рабочий .env/.secrets и не БД.
Исходники отдельного тестового клиента /opt/sp-game-bot сохраняются в том же
GitHub-снимке под tools/test-bot/; это путь дерева Git, не копия рабочего
кода в /opt/sp-game. Его runtime data/sessions и реальные .env не включаются.
Восстановление игровых данных по-прежнему выполняется из штатного снимка MySQL.
Для восстановления кода сначала сравнить нужную точку с локальными изменениями;
не делать автоматические reset/checkout --/массовую перезапись рабочего проекта.
