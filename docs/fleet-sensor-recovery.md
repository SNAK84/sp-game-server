# B005: исправление удаления Fleet при GC и восстановление «Сенсора»

23.10.2026. Пользователь разрешил исправление и восстановление только
snak84 / Player1 / owner_id=1 / account_id=1 / Fleet #38.

## Исправление

Убрано автоматическое игровое удаление из `Fleet::__destruct()`.
Сборка мусора и уничтожение временного PHP-объекта больше не означают
уничтожение Fleet. Явные `destroy()` и `FleetsData::remove()` работают как прежде.

Сенсоры сохраняют прежнюю семантику свежего чтения Swoole Tables через
отдельные Fleet. Причина устранена в lifecycle, а не замаскирована только
заменой трёх конструкторов. Общая архитектура Fleet, RepositorySaver,
команды и формула обнаружения не менялись; B004 остаётся отдельным багом.
